# Работа 3 — вариант 23

## Задание
Реализовать функцию `findLongestIncreasingSubsequence(arr)`, которая находит длину наибольшей возрастающей подпоследовательности.

## Состав
- `task3.js` — функция и пример использования.
- `README.md` — описание и инструкция запуска.

## Принцип работы
Функция принимает массив чисел и возвращает длину наибольшей строго возрастающей подпоследовательности. Элементы сохраняют исходный порядок, но могут идти с пропусками. Равные значения не увеличивают длину.

Для каждого элемента вычисляется длина самой длинной возрастающей подпоследовательности, которая заканчивается этим элементом. Просматриваются предыдущие меньшие элементы, и выбирается лучший результат. Для пустого массива возвращается 0.

Сложность по времени — O(n²), дополнительная память — O(n).

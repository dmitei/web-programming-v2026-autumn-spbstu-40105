# Лабораторная работа 3

## Задание

Вариант 23. Найти длину наибольшей строго возрастающей подпоследовательности.

## Реализация

Функция `findLongestIncreasingSubsequence(arr)` возвращает число. Элементы можно
пропускать, сохраняя их исходный порядок. Равные значения длину не увеличивают.
Для пустого массива результат равен нулю. Входной массив не изменяется.

Для каждой длины алгоритм хранит минимальный последний элемент возрастающей
подпоследовательности. Позицию очередного значения он находит бинарным поиском.
Время работы — O(n log n), дополнительная память — O(n).

## Запуск

```js
import {findLongestIncreasingSubsequence} from './solution.js';

console.log(findLongestIncreasingSubsequence([10, 9, 2, 5, 3, 7, 101, 18])); // 4
```

# Лабораторная работа 5

## Задание

Вариант 23. Создать страницу книжного магазина со списком книг и кнопкой
переключения темы в правой части шапки.

- Управлять светлой и тёмной темами через React Context API.
- Менять подпись и иконку кнопки при каждом переключении.
- Задать для тёмной темы отдельные цвета фона, текста, карточек и кнопки.

## Реализация

Контекст передаёт текущую тему и функцию переключения. Кнопка меняет текст и
иконку в зависимости от темы. CSS-переменные задают отдельную палитру для каждой
темы, включая фон, текст, карточки и кнопку.

## Запуск

В папке лабораторной выполните `npm install` и `npm run dev`. Откройте адрес,
который выведет Vite. Для сборки выполните `npm run build`.

На странице по умолчанию включена светлая тема. Нажмите «Тёмная тема» и
проверьте, что изменилась палитра страницы, а кнопка теперь предлагает светлую
тему. Нажмите её ещё раз, чтобы вернуться к исходной палитре.

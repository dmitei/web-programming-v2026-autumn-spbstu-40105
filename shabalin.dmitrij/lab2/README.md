# Работа 2 — вариант 23

## Задание
Реализовать функцию, которая генерирует случайный HEX-цвет, например `#FF0033`.

## Состав
- `task2.js` — функция `generateRandomHexColor()` и пример её вызова.
- `README.md` — описание работы и инструкция запуска.

## Как работает
Функция выбирает случайное целое число от 0 до 16777215, переводит его в шестнадцатеричную систему, дополняет нулями до шести символов и добавляет `#`. Буквы переводятся в верхний регистр.

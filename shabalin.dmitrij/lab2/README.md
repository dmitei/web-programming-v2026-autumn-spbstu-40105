# Лабораторная работа 2

## Задание

Вариант 23.Сгенерировать случайный цвет в формате `#RRGGBB`.

## Реализация

Функция `generateHexColor()` возвращает строку. Она выбирает случайное целое от
`0x000000` до `0xFFFFFF`, переводит его в шестнадцатеричную систему и при
необходимости добавляет ведущие нули.

## Запуск

Импортируйте функцию из ES-модуля:

```js
import {generateHexColor} from './solution.js';

console.log(generateHexColor());
```

# Лабораторная работа 4

## Задание

Вариант 23. Каталог игр с добавлением и удалением игр и платформ.

## Реализация

`model.js` экспортирует класс `Game`, две функции группировки (по году и
количеству платформ), список уникальных платформ и два фильтра (по платформе и
по году). Функции коллекции сохраняют исходный массив.

`main.js` выполняет операции через `Promise` и `setTimeout`, обновляет карточки
и сохраняет коллекцию в `localStorage`. После перезагрузки страницы игры и их
платформы восстанавливаются.

## Запуск

В папке лабораторной запустите `python3 -m http.server 8000` и откройте
`http://localhost:8000`. Введите название игры и год выпуска. Для добавления или
удаления платформы укажите её название в карточке игры.

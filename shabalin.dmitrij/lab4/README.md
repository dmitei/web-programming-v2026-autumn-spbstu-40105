# Лабораторная работа: задание 4, вариант 23

## Описание

Каталог игр. Управление играми и платформами с аналитикой, асинхронными изменениями и сохранением в localStorage.

## Состав

- `index.html` — интерфейс каталога.
- `model.js` — класс game и пять аналитических функций.
- `main.js` — интерфейс, асинхронные операции и сохранение данных.
- `styles.css` — стили страницы.
- `README.md` — описание и инструкция.
